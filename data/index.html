The record as data

The same rows the pages are built from, in tables you can sort and search. Every page on this site is an argument about one item; these are the rows behind all of them.

Nothing here is computed, scored or ranked. Each row names the document it came from, so a reader can go and check it. If a table and a page disagree, the page is wrong and we want to hear about it.
