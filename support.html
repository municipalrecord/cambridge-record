Every page on this site is free, with no paywall, ever — that doesn't change here. This page exists only for the fraction of readers who find it useful and want to help keep it running.

Why this exists

The project is unfunded: one Cambridge resident, run at personal cost — hosting, the city portals this site checks itself against, and the time to keep 176,000+ records straight. Nothing you read is gated behind this page. If it's been useful to you, chipping in helps it keep running; if it hasn't, volunteering as an auditor costs nothing and helps just as much.
