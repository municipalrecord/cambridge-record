How accurate is this site?

Audited 2026-09-11 · sample seed 20260712 · raw results (CSV) · audit code

This site is assembled by software (much of it AI-written) from the city's own portals. Software makes mistakes, so we measure ours in public: we drew 1,488 agenda items at random, with a fixed, published random seed, so anyone can re-draw the identical sample. We fetched the city's live page for each, and compared field by field.

What we compared

  • Tracking code (e.g. POR 2020 #173): 1474 byte-exact of 1,488; 14 differ only in the city's own spacing (“ORD 2023 # 9”). 0 mismatches.
  • Title: 247 byte-exact; 1210 differ only by the city's trailing punctuation (their display appends a period; verified by inspection). 0 content mismatches.
  • Meeting date: confirmed visible on 1484 of 1,488 city pages. The 4 exceptions are itemized below. In both, this site dates the item to the meeting whose agenda carried it, while the portal shows the clerk's next-day action date after a past-midnight adjournment.
  • Attachments (random subsample): 73/73 of the document links we mirror still resolve as valid PDFs at the city.

Votes & outcomes audit

Roll calls, outcomes, and sponsors on item pages come from a crawl of the city's own item records. Same discipline: we drew 150 crawled items at random (seed 20260713), fetched each city page fresh, re-parsed it, and compared status, sponsors, and every named vote. Result: 150/150 exact · 0 divergent · 0 fetch errors. raw results · audit code. Separately, every one of the 6,099 recorded roll calls must satisfy the city's own tally (“[4 TO 5]” must equal exactly 4 + 5 parsed names) or it is withheld from display. 0 failed that check in the current build.

Method, honestly

The comparison is against what the city's portal displays today: if the clerk edits a record after we capture it, that surfaces here as a deviation. The auditor is software too, so the code and raw results above exist for checking the checker. This page regenerates with every audit run. Found something wrong anyway? Every page has an error-report link in its footer, and corrections are public.
